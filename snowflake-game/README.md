# ❄️ Snowflake vs Databricks: Data Warehouse Battle

A fun and interactive web game that playfully showcases Snowflake's advantages over Databricks in the data warehouse space!

## 🎮 How to Play

1. **Choose Your Attack**: Click on any of Snowflake's advantage buttons to launch an attack
2. **Watch the Battle**: See health bars decrease and battle messages appear
3. **Win the Game**: Reduce Databricks' health to 0 to claim victory!
4. **Auto Play**: Use the auto-play feature to watch Snowflake dominate automatically

## 🚀 Features

- **Interactive Battle System**: Click buttons to attack with different Snowflake advantages
- **Real-time Health Tracking**: Visual health bars for both platforms
- **Battle Log**: See detailed messages about each attack
- **Auto Play Mode**: Watch the battle unfold automatically
- **Responsive Design**: Works on desktop and mobile devices
- **Modern UI**: Beautiful gradients and animations

## 🏆 Snowflake Advantages Highlighted

- ⚡ **Performance**: 10x faster queries with columnar storage
- 💰 **Cost Efficiency**: Pay-per-use model vs expensive idle compute
- 📈 **Auto-scaling**: Automatic scaling without manual intervention
- 🔒 **Enterprise Security**: Bank-grade security features
- 🎯 **Zero Management**: No infrastructure to manage
- 🤝 **Data Sharing**: Share data without copying

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and accessibility
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **JavaScript**: Interactive game logic and DOM manipulation
- **Google Fonts**: Inter font family for modern typography

## 📱 Deployment

This game is designed to be deployed on GitHub Pages. Simply:

1. Create a new GitHub repository
2. Upload all files to the repository
3. Enable GitHub Pages in repository settings
4. Your game will be live at `https://yourusername.github.io/repository-name`

## 🎯 Educational Purpose

This game is created for educational and entertainment purposes to highlight the differences between Snowflake and Databricks in a fun, interactive way. It's not meant to be a comprehensive technical comparison but rather a playful introduction to these platforms.
